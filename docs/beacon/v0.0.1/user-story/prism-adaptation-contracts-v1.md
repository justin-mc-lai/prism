# User Stories — prism-adaptation-contracts-v1（Lake F2）

## US-ADP-001 改编授权

改编意向 → 按 `adaptation.contract` 登记授权（范围/条款/分成）→ 人工批准 → 才可谈改编。

## US-ADP-002 未授权拒绝

缺 approval/evidence → blocked，不自动授权。

## US-ADP-003 合同信息

走受管 secrets，禁止入库。
