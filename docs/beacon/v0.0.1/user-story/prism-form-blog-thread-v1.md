# User Stories — prism-form-blog-thread-v1（Lake D2）

## US-FORM-001 Blog 深度长文

intel 定角度 → master 冻结 FactMaster → director 出 treatment → prism-produce 按
`form-blog.contract`（四段式：场景开场 → 🎯本质 → 🗺️架构 → 💎亮点 → ⚠️坑点）成稿 →
qa 过 anti-slop-gate + 事实核对 → release。

## US-FORM-002 Thread 快道

用户只调 prism-goal；lane=fast；intel/master/director 以 `fast_lane_skip` 标注跳过 →
produce 按 `form-thread.contract`（倒金字塔：hook → 证据 → 观点 → 行动）→ qa → release。
canon lane 禁用快道。

## US-FORM-003 新增形态

只改 registry + form contract + 路由表；主链与导演骨架不动。
