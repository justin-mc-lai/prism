本文件是 Prism 仓内宪法投影；变更须走 Prism 版本 change，不得静默改写。

## 身份

- **Prism（棱镜）**：内容营销创作规范与内容 truth
- **Beacon**：编码/工程 truth（只读理念对照）
- 对齐范围：**设计理念与调用形状（1+6 / 契约 / 门禁 / 人类卡 / anti-leak）**；不对齐编码能力复制

## 海与湖

- 海级承诺：完整自媒体内容创作能力
- 交付：分湖（A 宪法 → **B 独立仓提取** → C campaign schema → D 形态生产链 → E 回流 → F 变现可选）
- 本仓首版 `v0.0.1` 目标 = **Lake B**：独立仓 + 公开面壳 + 编排内核 + adapter 索引

## First principles（继承）

见源包 FP-PRISM-001…013。硬约束摘要：

1. 内容 truth 与工程 truth 分轨
2. 母稿权威；展示变体不得新增事实/正典
3. maker ≠ checker
4. 公开发布必须人工批准
5. 公开面固定 1+6；子 skill 不可见
6. 不得把文档冻结伪装成全海能力已交付
