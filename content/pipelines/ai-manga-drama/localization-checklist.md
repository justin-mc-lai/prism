# 海外本地化检查单（localization-checklist）

每个出海选题成片前逐项核对；任一未过 → 不得进入 ReadyForReview。

## 1. 台词重构

- [ ] 无中文网络梗、拼音谐音、直译腔；台词符合目标语言自然表达。
- [ ] 对白长度适配口型/字幕节奏（每句不超过 12-14 个英文词为宜）。

## 2. 敏感题材

- [ ] 无扇巴掌、下跪、霸凌虐待、儿童危险等高危情节。
- [ ] 暴力/冲突画面有明确风格化处理（本管线默认漫画风格化）。

## 3. 价值观

- [ ] 不强化种族/性别/宗教刻板印象；尊重目标市场文化禁忌。
- [ ] 结局/立场不违反目标平台社区准则。

## 4. 平台版权规则

- [ ] 确认素材无第三方角色/IP/音乐版权；原创角色与场景。
- [ ] 记录分发平台的 AI 内容标注要求（如 YouTube AI 披露、Content ID 申诉预案）。
