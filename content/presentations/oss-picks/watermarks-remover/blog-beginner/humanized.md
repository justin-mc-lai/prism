# AI 会在你的文件里藏水印，这是查出来并清掉的工具

> 库拾一句话：一个 4 天涨到约 8.5 千星的开源工具，能查出并清理文本和图片里的 AI 溯源水印，官方边界是「只对你拥有的内容动手」。

信息更新于 2026-08-15（star 数为检索时刻快照）。项目地址：github.com/guillaumemeyer/watermarks-remover · 协议 MIT · 核心 Python。

## 先说你可能遇到的事

你用 AI 写了一段稿子，发给同事，对方回了一句「这段是不是 AI 写的」。你愣了一下，因为你自己都说不清为什么会被看出来。

其实不止是语气。AI 生成的文件里，可能藏着几层看不见的痕迹。不可见的 Unicode 字符、统计层面的采样水印、还有藏在图片和文档元数据里的 C2PA 标记。你复制、粘贴、转发的时候，它们跟着走。

大部分人的反应是「算了，不深究」。但如果你手里的文档、图片是你自己的资产，你至少该知道里面有什么。

## 🚀 小白 MVP：先查再清

环境前提：有 Python 3.10+ 就行，核心脚本只用标准库，不用装第三方包。

先查一份文件：

```bash
python3 service/scripts/inspect_file.py draft.md
```

想清理：

```bash
python3 service/scripts/clean_file.py draft.md -o draft.cleaned.md
```

跑通检查清单：

- `inspect` 输出了报告（不是报错）
- `clean` 生成了 `.cleaned.md`
- 图片用 `inspect_image.py` / `clean_image.py`，别用文本命令硬读

三句口诀：

1. 先查后清，查不到就别硬清。
2. 文本用文本命令，图片用图片命令。
3. 只动你自己的文件。

## 🎯 一句话看透本质

它是一台「AI 溯源痕迹的体检 + 清理机」。输入文本或文件，输出报告和清理结果。痕迹分三层。不可见 Unicode 字符、统计采样水印、文件元数据（C2PA/EXIF 等），每一层有不同的处理方式。

它对你有用的原因，是你自己的内容你该有知情权。它不负责帮你骗过谁，官方定位写得很清楚，privacy and hygiene on content you own。

## 🗺️ 核心架构与主流程

先懂白话版：

1. 你丢给它一个文件路径。
2. 脚本按扩展名和魔数判断类型，路由到对应处理器。
3. 你拿到报告和清理后的文件。

进阶：同一套逻辑有两条入口。

| 入口 | 用法 | 适合谁 |
|------|------|--------|
| CLI 脚本 | `inspect_file.py` / `clean_file.py` 等 | 想手动查清文件的人 |
| HTTP 服务 | `python3 service/scripts/server.py --port 8765` | Agent skill 或网页应用集成 |

文本层是确定性脚本（Unicode 卫生）；统计层是改写钩子，默认只打印改写提示（`print-prompt`），不接模型也能跑；文件层清理可选配 c2patool / exiftool / qpdf 三个系统工具，PDF 的真实清理需要 qpdf。

## 💎 绝妙的设计亮点

1. **纯标准库**：核心脚本只用 Python 3.10+ 标准库，无依赖、无 Docker 必需，一条 `make serve` 就能跑。
2. **文本工具拒绝二进制输入**：拿 `.docx` 给文本命令，它会拒绝并告诉你该用哪个工具，而不是把压缩字节当文本改写毁掉文件。
3. **API key 只走环境变量**：`WATERMARKS_REWRITE_API_KEY` 绝不进命令行参数，远程改写端点默认关闭，要显式开。

## ⚠️ 潜在坑点与局限性

- **统计水印没有保证**：Layer B 靠模型改写，效果因文本和模型而异，README 没有承诺检测率。
- **PDF 不是开箱即用**：真实 PDF 清理需要 qpdf 参与，光有脚本不够。
- **边界是硬约束**：两个 harness（像素级去除、SynthID 评分）因为上游 license 问题**从不发布**；这提醒你，这工具的设计者自己就在守线。
- **数据会变**：8,509 stars / 876 forks 是 08-15 的快照，会随时间变化。

话说回来，这些坑大多有解。先 inspect 再决定，图片用图片工具，PDF 装好 qpdf。

## 接下来你可以

1. 拿一份你自己的 `.md` 或 `.png` 跑一次 `inspect_file.py`，看看有没有隐藏痕迹。
2. 想给 AI 助手装能力：按 README 把 `skills/remove-ai-marks` 链进 agent 的 skill 目录。
3. 想批量处理：把服务跑起来，按 `/clean` 接口的 OpenAPI 契约接进自己的脚本。
