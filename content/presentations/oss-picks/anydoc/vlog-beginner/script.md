# 口播稿（60s · vlog 路由）

> 形态 av（vlog）· 标准 lane · 母稿见 content/masters/oss-picks/anydoc/MASTER.md
> 字数约 260 · 按气口断句 · 素材为显式占位

【0~3s · S1 乱码文档特写】

同事发来 Word，你把内容复制进笔记或编辑器，标题乱码，表格散架，图片失踪。你手动整理一份，二十分钟没了。

【3~15s · S2 大字卡】

这个月 GitHub 上有个开源小工具，九天涨到约 1.5 万星。它叫 anydoc，MIT 协议。

【15~30s · S3 命令录屏】

它做的事一句话就能讲完，把 Word、PPT、PDF、Excel 这些办公格式，统一变成干净的 Markdown。

用起来更简单，一条命令。

`npx @firecrawl/anydoc 你的文档.docx`

想批量处理，Node 和 Python 有现成 API。

【30~42s · S4 浏览器示意】

在意隐私的注意这条。浏览器版用 WebAssembly 在本地转，文件不上传。

【42~52s · S5 边界文字卡】

说个边界。扫描版 PDF 它转不了，本体不做 OCR，那要官方托管 API。

【52~60s · S6 行动字幕】

拿一份手边文档试一次，三分钟知道值不值。数据是 08-12 的快照，会变。
