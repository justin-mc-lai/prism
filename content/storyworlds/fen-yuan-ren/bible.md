# 世界圣经 · 美利坚：焚怨人

## 1. 一句话世界观

平行世界的美利坚，都市暗面堆尸成怨：死人若含冤而死，怨念不散，
会从停尸房里爬出来，长成“诡异”。联邦焚尸场是挡在人与诡异之间的第一道炉火，
焚尸人烧的不是尸，是没烧干净的恨。

## 2. 怨念体系（本作核心设定）

怨念 = 未偿之冤。人死时若被冤、被辱、被弃、被杀而无处申诉，
执念会凝在尸体里，成为怨念。怨念五色：

| 色 | 来源 | 表现 |
|----|------|------|
| 黑 | 恨 | 杀人、仇怨，最具攻击性 |
| 红 | 惧 | 死前恐惧，会反复重演死亡瞬间 |
| 灰 | 悔 | 未了之愿、来不及说的话 |
| 青 | 贪 | 图财害命留下的印记 |
| 白 | 执 | 执念最纯，也是超度后最亮的光 |

怨念浓度七阶：微、轻、重、深、煞、灾、神诡。浓度越高，
尸体“起尸”成诡异的可能越大。焚尸的本质是把怨念烧净：
烧得净是超度，烧不净是放鬼。

## 3. 诡异等级

| 等级 | 名称 | 说明 |
|------|------|------|
| D | 残 | 只会复读死者最后动作的残影 |
| C | 凶 | 有攻击性，物理可伤 |
| B | 厉 | 会设局、有执念目标，普通武器难伤 |
| A | 煞 | 区域性灾祸，能改写入室之人的记忆 |
| S | 灾 | 一座城的天灾，需要多名执炉人合力 |
| SS | 神诡 | 传说级，档案局称“不可直视之物” |

焚化诡异尸体可得到“诡词条”，比普通词条多一层对诡异特攻属性。

## 4. 焚尸人能力体系

焚尸人通过【焚怨人系统】焚烧尸体获得词条。词条 = 死者生前一生的切片，
被炉火压成一条能力。怨念越重、死状越冤，词条越强，风险也越大。

例：

- 焚化老刑警尸体 → 【蛛丝马迹】：看清尸体上残留的最后线索。
- 焚化拳手尸体 → 【拳骨】：继承肌肉记忆的一击。
- 焚化 A 级诡异 → 【净怨圣焰】：可点燃怨念的火，对诡异特攻。
- 焚化怨念极深的受害者 → 【亡者独白】：听见死者最后没说完的话。

### 阶位（焚尸人等级）

见习（1–3阶）→ 正式（4–6阶）→ 执炉人（7–9阶）→ 炉主（10阶+）。
初始 2 个词条槽，之后每升一阶多一个词条槽；
三阶、六阶、九阶分别解锁：词条融合、炉中界、怨案回廊。

### 怨案回廊

三阶正式解锁。焚化惨案受害者的尸体时，焚尸人会被拉进死者记忆拼成的案发现场，
重历案发经过，找出未偿之冤并了结它，超度后可获得该案的专属词条。
代价：重历的痛会原样压回焚尸人身上。

例外：系统可在煞级以上的紧急怨案中提前开启回廊，代价是宿主体温下降一档
（本作倒计时机制，见母稿埋点 B）。

## 5. 组织与角色（骨架）

- 联邦焚尸场第 7 区：主角江烬的单位。
- 档案局：登记诡异与焚尸人的神秘机构，从不公开露面。
- 江烬：华人青年，魂穿到平行世界美利坚，觉醒系统，体温偏低，记忆有缺口。
- 老科尔：带江烬入行的老焚尸工，话不多，手上有烧伤。
- 白鸽：反复出现的白色鸽子，每次出现都伴随一次转折。

## 6. 基调铁律

- 抒情：每一具尸体都是一段没讲完的人生；火里烧的是来不及说的话。
- 热血：诡异再凶，也要为死者讨一句公道；焚尸人是给死人守夜的人。
- 埋点：所有异常（体温、白鸽、系统来历、江烬的记忆缺口）都必须登记、回收。
- 禁忌：不美化凶手，不消费受害者，不写猎奇式细节堆砌。
