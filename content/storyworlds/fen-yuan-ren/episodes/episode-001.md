# 第 1 章 · 第 7 区的第一炉火

> 正文草稿 · 正典门待复核（review_required）· 未冻结前不得视为正典

夜里十一点四十，第 7 区焚尸场的灯只剩下一盏。

那盏灯挂在三号炉的上方，铁皮灯罩被烟熏成焦糖色，光落下来是斜的，
像有人拿刀把黑暗切掉了一个角。江烬站在光与光的边缘，戴着手套，
把最后一张停尸床推上轨道。

轮子碾过地砖的声音很钝，一下一下，像有什么东西在敲夜的门。

这里是美利坚的背面。白天有阳光、汉堡、插在草坪上的星条旗；
夜里，全城的尸体都沿着地下隧道，一车一车地送到这儿来。第 7 区不熄火，
因为死人太多，而炉火太短。

江烬入职第三十七天，还是没习惯那股味道。那不是臭，是甜。
消毒水压不住的那种甜，混着骨头发烧的焦香，钻进口罩，贴在喉咙里。
老科尔说，这是死人的糖分。烧多了，你会开始觉得它是香的。

“第三十七天了。”江烬把炉门拉开一条缝，热气扑出来，他的眼睛眯了眯。

老科尔没抬头，蹲在地上检查阀门，声音隔着口罩，闷闷的：
“想走的人，第一天就走了。留下来的，都是走不掉的。”

这句话江烬听懂了，也没听懂。他抬起手腕，看了一眼表盘。
数字没有跳，三十二点四度。他的体温。

系统面板在他眼前展开，半透明，像一块贴在空气里的碎玻璃。

```
【焚怨人系统】
宿主：江烬
阶位：见习一阶
词条槽：1/2（空）
薪火值：0
```

他第一次看到这块面板，是在穿越过来的那个雨夜。他在一间陌生的地下室醒来，
后颈烫得像被烙铁按过，口袋里只有一张焚尸场的聘书，上面写着一个不属于他的名字。
江烬。烧尽之后，只剩灰烬的“烬”。

他记不起穿越前的七天，记不起自己的本名。像有什么人，趁他睡着的时候，
把他人生的一页撕走了。

表盘上的数字停在三十二点四度。一个活人不该是这个温度。

炉门全开的时候，江烬把今晚的最后一具尸体推进去。老科尔曼，前联邦探员，
六十一岁，死于突发心脏病。他的妻子三天前签了火化同意书，签完就哭了，
说科尔的枪还没摘下来。

“老科尔曼。”江烬低声说，像在跟一个还能听见的人打招呼，“你查了一辈子案，
最后一案，是你自己。走好。”

他按下点火。蓝色的火苗先是犹豫了一下，然后轰地蹿起来，
把尸体的轮廓舔成一道漆黑的剪影。就在火焰吞没胸口的一瞬间，
系统面板猛地一亮。

```
【叮】焚烧尸体（老科尔曼 · 联邦探员）。怨念：微（灰）。
怨念转化中……
【蛛丝马迹】已获得。
词条槽 1/2 已填充。
词条说明：焚烧尸体时，可看见死者身上最后残留的线索，持续七秒。
```

江烬的瞳孔一缩。炉火里的尸体突然“动”了一下。不是动，是火光的重影。
他在重影里看见一只手。苍白的、布满老年斑的手，在虚空中反复摩挲着左胸口袋。
七秒，不多不少。

他顺着那只手的动作看去，看到老科尔曼胸口的内袋里，别着一张照片。
照片已经烧起来了，只剩一个角。上面是一个穿红裙子的女孩，站在一所学校的门口。

江烬没来得及看清。七秒结束，炉火恢复原样，只剩骨头在火里塌下去，
发出一声轻响，像有人合上了一本书。

“烧干净了，才能安息。”他低声说。这是老科尔教他的第一句话，也是他唯一相信的咒语。

三号炉的火还没熄，外面就传来了卡车的刹车声。

那声音在夜里格外刺耳，紧接着是铁门被拍响的声音，不是敲，是拍，
又急又重，像后面有什么东西在追。

老科尔站起来了。江烬看见他的右手在发抖。那只手上全是烧伤的疤，
五道，一道叠着一道，像有人在他年轻的时候，抓住他的手，一起伸进过火里。

“送货的。”江烬去开门。

门外的夜色浓得像墨，一辆冷藏车歪在路牙上，司机瘫坐在驾驶室里，
脸色白得跟纸一样。他指着后车厢，嘴唇哆嗦了半天，只说出一句话。

“里、里面的东西……在哭。”

江烬和老科尔对视一眼。他们一起拉开了后车厢的门。

冷气涌出来，白茫茫的，像打开了一个冬天的口子。车厢里停着两张床，
一男一女，肩并着肩，白布盖到胸口。男的手腕上缠着一截红绳，
女的手腕上也缠着一样的一截。那是一对新人，结婚还不到一年。

他们安静地躺在那里，像两个睡着了的人。

可江烬听见了哭声。

不是从耳朵里，是从后颈、从锁骨、从每一寸贴着冷气的皮肤下面涌上来的……
一个女人在哭，哭得很轻，压着嗓子，像怕吵醒身边熟睡的丈夫。

与此同时，系统面板疯了似的弹出来，字是红的。

```
【怨案提示】检测到未偿之冤。
案件：费岭镇新婚夫妻案（改编自公开案件，人物已虚构化）
怨念：黑（恨）·浓度：煞
诡异孕育度：71%……78%……85%……
任务发布：怨案回廊，八小时。
提示：宿……主……档……案……（信号中断）
```

“别碰白布。”老科尔的声音第一次发抖了，他死死按住江烬的手，
“黑怨。煞级。这俩口子，死的时候没合眼。”

江烬看着那两具尸体。女人的脸被白布盖着，只露出一缕头发，贴在耳边，
还带着一点洗发水的香气。那香气混进冷气里，混进哭声里，混进这间焚尸场
几十年没散过的焦味里。

他忽然觉得喉头发紧。

一个陌生人，用他听不懂的语言，在一个他已经死过一次的夜晚里，
把没说完的话，哭进了他的骨头。

他听见自己问：“他们……是怎么死的？”

老科尔沉默了五秒。五秒里，哭声大了起来，整个车厢都在轻微地震。

“入室抢劫。四个男的，最小的十九岁。”老科尔的声音干得像炉灰，
“他们捆了丈夫，当着丈夫的面，把他的妻子……”

他没说下去。有些事，连在焚尸场干了二十八年的人，也说不出口。

“八个小时。”老科尔最后说，“从进门到最后一刀，八个小时。
他们被扔进山洞的时候，丈夫还活着，红绳是妻子出事前系在他腕上的，
说是平安绳。”

江烬低下头，看见自己推床的手在抖。不是因为冷。

三十二点四度的人，此刻却觉得心口有火。

“报警了？”他问。

“结案了。”老科尔说，“人都抓了，判了。可你看……”

他指了指车厢。江烬看过去，白布下面，两具尸体的胸口，
各浮着一团黑色的东西，像墨，又像烟，在冷气里缓缓蠕动。

“人抓住了，法也判了，”老科尔一字一顿，“可他们俩，不知道自己赢了。
死人的恨不知道案结了。它只知道，坏人死得太慢，而他们疼得太久。”

江烬忽然明白了这份职业的真相。

焚尸场不是处理尸体的地方。是给死人一个“知道了”的地方。

炉火不是毁灭。是最后一遍、由活人替死人说的。

你受的苦，有人记得。你咽不下的那口气，我替你烧干净。

他松开老科尔的手，走到两具尸体中间，慢慢掀起了女人脸上的白布。

白布落下的那一刻，哭声停了。

车厢里安静得可怕。然后，江烬看见她的睫毛动了一下……
不，是她的眼睛，缓缓睁开了。

漆黑的眼珠里，没有瞳孔，只有一条倒流的、血红的长夜。

系统的最后一行字，在冷气中亮了起来。

```
诡异孕育度：100%
【四首煞】已诞生。
```

而城市的另一头，一只白鸽停在钟楼的尖顶上。

它望着第 7 区烟囱冒出的第一缕夜烟，雪白的羽毛在风里一根根竖起来，
像是听见了什么，从很远很远的地方，正在醒来。

（第 1 章 · 完）
