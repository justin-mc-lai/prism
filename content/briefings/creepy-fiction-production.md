# Intel Briefing — 诡异小说稳定生产配方（探索）

- mode_id: brief-intel · public_id: intel · lane: standard
- recommended_next_harness: master
- 目标: 借鉴“美利坚·烧尸人”式都市怪谈的定位（烧尸人意象 + 真实案件改编 + 怨念体系），建立可复用稳定产出配方
- 声明: 未取得原文本，以下为原创设定；真实案件全部脱敏、情节为虚构演绎

## 风格要素（用户给定）

1. 烧尸人意象：职业化处理“怨念/尸体/未烧尽之物”的人
2. 真实案件改编：国内外暗黑案件作为素材，梳理进故事
3. 怨念体系 + 诡异等级能力（升级感）
4. 抒情（打动）+ 埋点（伏笔）+ 热血（对抗高潮）

伦理边界（写进正典，QA 必查）：
- 不使用真实受害者姓名；不渲染性暴力细节；不美化凶手；每篇文末注明“虚构演绎”
- 案件梗概只保留公开报道层面，不编造受害者细节

## 稳定产出配方（五件套）

1. **怨念五阶**：余烬 → 焚线 → 火场 → 焚域 → 焚主（升级刻度）
2. **烧尸人五级能力**：见火 → 借火 → 引火 → 焚契 → 业火（能力升级 + 代价）
3. **节拍模板**：钩子（接单/异象）→ 档案（案件引入）→ 探查（升级）→ 抒情（未说完的话）→ 反扑（热血）→ 余韵（埋点）
4. **埋点清单**：每篇 ≥3 个（物件/名字/日期/温度），结尾留 1 个续集钩
5. **QA 检查表**：正典一致（怨念阶/能力代价）、案件脱敏、anti-slop、埋点回收

## 结论

按“案件档案化 + 怨念体系 + 五级能力 + 节拍模板 + QA 正典检查”可稳定产出；
本篇即为配方验证（第 1 集）。
