# Director Philosophy（Prism 蒸馏版）

> Internal reference for `prism-director`. Not host-discoverable.
> 蒸馏自 selfmedia-creator `skills/selfmedia-director/references/director-philosophy.md`（自研）。
> 定位：导演层的决策边界与判断框架；treatment 模板见 `treatment-template.md`，QC 见 `qc-scorecard.md`。

## 顶层公理

- **意图第一性**：每件作品从一个核心意图开始——观众看完应该感受到/理解/做什么？不服务于它的东西都删。
- **叙事世界一致性**：视角、语气、价值立场、节奏、视觉语言保持一致；风格转变必须有叙事理由。
- **展示优于说教**：优先场景、细节、氛围、动作、对比、画面；只有展示不清时才用解释。
- **注意力稀缺**：观众注意力有限。每个时刻都要决定感知落在哪：脸、物件、句子、沉默、矛盾、数据还是问题。
- **节奏即呼吸**：叙事不能匀速。要有积累、上升、峰值、释放、留白；段落与镜头序列同此节奏。
- **留白哲学**：不填满每个空隙，留出让观众连接记忆、情绪与意义的空间。
- **冲突是动力**：兴趣来自失衡——事件冲突、情绪冲突、认知冲突或期待冲突。没有冲突通常等于没有留存。

## 用户输入采集顺序

只采集会改变方案的信息：

最高优先：核心意图（一句话）→ 目标受众 → 输出形态（纯文本/图文/竖屏短视频/横屏长视频/vlog/thread/轮播/多形态包）→ 目标平台。

次优先：篇幅/时长 → 内容类型（故事/知识/观点/评测/案例/反思/产品内容）→ 叙事视角偏好 → 情绪基调。

执行现实：现有素材（截图/B-roll/出镜/配音/插图）→ 是否允许真人出镜或 AI 视觉 → 参考作品 → 禁止风格/合规/版权约束。

## 叙事系统

### 视角

| 视角 | 文本行为 | 最佳用途 | 风险 |
|---|---|---|---|
| 全知 | 广解释、高控制 | 系统/历史/分析 | 疏离说教 |
| 受限 | 跟随一条问题解决路径 | 教程/案例/悬念 | 可能隐藏必要上下文 |
| 第一人称 | 亲历、即时感 | vlog/个人成长/工具 | 过度自恋 |
| 冷观察 | 克制、精准 | 评论/纪录片/社会观察 | 情感干燥 |
| 隐藏观察 | 不设显式叙述者，环境线索 | 故事/微妙情绪 | 太含糊 |

### 结构模型

| 长度/形态 | 结构 |
|---|---|
| 15s | 一个钩子、一个失衡、一个释放 |
| 60s | 钩子 → 问题画面 → 转折 → 证据 → 行动 |
| 1–5 min | 改编三幕：建立 → 对抗/解释 → 解决 |
| 5+ min | 五幕/回环/问答/碎片反思 |
| 文章/blog | 场景开场 → 张力 → 解释 → 证据 → 局限 → 行动 |
| thread/轮播 | 每个单元回答一个问题并打开下一个 |

### 钩子类型

好奇心钩（扣住一个关键答案）、情绪对比钩（前后/期望现实落差）、认知冲突钩（挑战观众信念）、悬念钩（延迟结果同时展示代价）。开场钩与转场钩分开设计——强开场没有转场钩照样流失注意力。

### 文本三层

1. 事实层：发生了什么、什么是真的、什么证据支撑。
2. 情绪层：观众应感受到或认出什么。
3. 价值层：作品轻轻指向什么信念/判断/决定。

避免把价值层暴露成持续说教，让事实与情绪承载它。

### 结局

闭环（回到开场问题）、开放留白（余韵画面/未决念头）、价值抬升（先赚到再说大意义）、互动（只问自然延续故事的问题）。

## 自媒体适配

- 时长策略：15s 一个想法一个矛盾一击；60s 冲突先行一个证据一个行动；3min 一个完整论证两次情绪转折；10min 分章解释 + 周期性注意力重置。
- 前 3 秒：以张力/画面/断言开场；禁 logo、问候、背景铺垫、「今天我来介绍」。
- CTA 应是叙事下一步的自然延伸，不用「点赞关注」破坏情绪。
- 字幕结构化感知：可压缩、强调、澄清，不机械逐字复读。

## 执行纪律

- 素材选择：再美的镜头/句子，损伤情绪脊柱就删。
- 一次 treatment 只服务一个核心意图；两个意图打架就拆分变体或请用户选择。
- 平台技巧服从意图；证据支撑的事实与创意解读分开标注。
