## 0. 术语与归属

- **分镜（sequence shot）**：一个 15 秒生成单元，是节奏与拼接口的边界。
- **子镜（beat）**：分镜内的一次切点，3-5 秒，是**音效与站位的最小宿主**。
- 本表规则**只覆盖分镜脚本层**；资产 ref、母稿事实、QA verdict 不在此表（属各自的门）。

## MJ-UNIT 生成单元与节拍（§2.1）

| ID | 规则 |
|---|---|
| MJ-UNIT-01 | **每个分镜固定 15 秒**（节奏基准单元）。 |
| MJ-UNIT-02 | 分镜内部细化为 **5-8 个子镜**。 |
| MJ-UNIT-03 | **每个子镜分配 3-5 秒**。 |
| MJ-UNIT-04 | **特写镜占 20%-30%**；每分镜 5-8 子镜中至少 1-2 个特写（眼睛/嘴唇/手/法宝/环境细节）。 |
| MJ-UNIT-05 | 15 秒不够用时可**增加或减少分镜数量**，以剧情完整与节奏舒适为准（不硬凑时长）。 |

> 调和说明（源文档内部有松量）：`5-8 子镜 × 3-5s` 与「固定 15s」不能同时严格成立。
> 本表按**意图**执行：分镜目标 12-18s，子镜 2-5s，子镜时长之和 = 分镜时长（以合为真）。
> 门只校验「和相等 + 子镜数 5-8 + 每子镜 2-5s」的软区间，不硬卡 15。

## MJ-FIELD 子镜字段定式（§2.1 / §2.2）

| ID | 规则 |
|---|---|
| MJ-FIELD-01 | 每个子镜必须包含：`【人物:】【场景:】`（以及 `【兵器:】【法器:】【坐骑:】`，若有）`+ 景别 + 运镜 + 画面特效 + 台词（含情绪 + 语速）+ 音效`。 |
| MJ-FIELD-02 | **音效不可写"无"**，每个子镜必须有具体音效（≤10 字，见 MJ-SFX）。 |
| MJ-FIELD-03 | 人物栏/兵器栏**仅写名称**；状态变化（受伤/觉醒/透明化）一律写进「画面效果」描述，不在栏位标注。 |
| MJ-FIELD-04 | 每个分镜结束后单独一行写固定行：`音频要求：不要背景音乐，不要字幕，不要解说声音。` |

## MJ-LINE 台词与时间线（§2.3 / §2.3.1）

| ID | 规则 |
|---|---|
| MJ-LINE-01 | **单个小镜头的台词（含内心独白）≤30 字**；超过 30 字必须拆分到两个及以上子镜，或拆到下一分镜。 |
| MJ-LINE-02 | **字数→秒数**：正常语速 **5-6 字/秒**；情绪激动稍快 **7-8 字/秒**；情绪低沉/威严稍慢 **4-5 字/秒**。 |
| MJ-LINE-03 | 台词秒数 = 字数 ÷ 语速；据此划分时间线（每子镜的占用秒数）。 |
| MJ-LINE-04 | **语速必须匹配情绪**：愤怒稍快但咬字清晰，平静沉稳缓慢，冷漠一字一顿，蔑视慵懒慢悠悠，威严中速带回响；不能过快也不能过慢。 |
| MJ-LINE-05 | 若某子镜台词明显说不完：将该子镜延长至 5-6 秒，或将台词拆到下一分镜开头；15 秒不够可合并/增减分镜（同 MJ-UNIT-05）。 |

| MJ-EMO-05 | 威严 | 中速带回响 | 如天钟震荡、如雷 |
| MJ-EMO-06 | 恐惧 | 颤抖、渐弱 | 绝望、变调 |
| MJ-EMO-07 | 内心独白 | 极慢 | 空洞、带回响、迷茫 |

## MJ-CONT 穿帮与逻辑连贯（§2.5）

| ID | 规则 |
|---|---|
| MJ-CONT-01 | 上下分镜之间的**动作、视线、情绪、位置关系**要自然衔接，避免跳跃。 |
| MJ-CONT-02 | 同场景内**人物站位、道具位置、服装、光照方向、天气状态**必须前后一致。 |
| MJ-CONT-03 | **人物一致性**：同一角色同场景的外貌、服装、状态（受伤/完好、觉醒/未觉醒）一致；状态变化必须写进画面描述。 |
| MJ-CONT-04 | **场景一致性**：物品摆放、光线角度、季节/天气特征前后呼应。 |
| MJ-CONT-05 | **道具连贯**：被抢走的令牌、储物袋等，后续不能再出现在原主人身上。 |
| MJ-CONT-06 | **时间连贯**：白天/黑夜、室内/室外、受伤/愈合等状态连续。 |
| MJ-CONT-07 | **镜头转换流畅**：上下分镜之间用眼神、动作、空间扭曲、黑屏、心跳声等方式自然过渡。 |
| MJ-CONT-08 | 角色不能凭空出现或消失。 |

## MJ-BLOCK 人物持久在场与精准站位控制（§2.5.1 / §2.5.1.1）

> 面向 Seedance 2.0「人物凭空消失 / 出现多余人物 / 站位漂移」的**抗幻觉控制语句**。
> 每个子镜的画面描述中必须包含以下控制语句（对应无状态采样：模型不跨调用记忆在场）。

| ID | 规则 |
|---|---|
| MJ-BLOCK-01 | 每个子镜必须明确标注 **"画面内共计 X 人"** 或 **"画面内仅 XXX 一人"**。 |
| MJ-BLOCK-02 | 多人镜头必须标注 **"严格 X 人，无第四人/无他人"**。 |
| MJ-BLOCK-03 | 用**精确方位词**定位：左侧、右侧、中央、左前、右后、身后两侧、一左一右。 |
| MJ-BLOCK-04 | 单人特写必须标注 **"画面内仅 XXX（部位/全身），其余人物位于画外[具体方位]空间不变"**。 |
| MJ-BLOCK-05 | 人物进入画面必须有明确**入场动作**；离开画面必须有明确**离场动作**。 |
| MJ-BLOCK-06 | **若角色未明确离场，则默认其始终在场**；后续镜头即使聚焦他人，也须在背景或画外标注其存在。 |
| MJ-BLOCK-07 | **第一镜头**：人物首次进入场景时，标注全体人物数量及站位关系。 |
| MJ-BLOCK-08 | 切换到另一组人物时，标注"背景虚化区域可见[之前在场人物]轮廓，始终在场"。 |
| MJ-BLOCK-09 | 若有人物移动位置，标注移动后的具体方位。 |

## MJ-CHAR 人物四视图（三：人物四视图）

**光效标准（MJ-CHAR-01）**：四视图只需"照亮全身"，**不要艺术打光**。
- 允许：均匀柔和打光、光线明亮通透、无明显阴影、整体清晰干净、轻微暖环境光。
- 禁止：主光源左上方 45 度、侧逆光、轮廓光、强光束、丁达尔光、金光直射、佛光、圣光、任何精确角度光。

**眼神标准（MJ-CHAR-02）**：眼神必须沉稳、深邃、自然，**不写具体颜色细节**。
- 允许：双目深邃如渊、目光深邃、眼神沉稳、目光平静、目光如炬。
- 禁止：瞳孔漆黑如墨、虹膜清晰自然、瞳孔正常等过度具体眼部细节。

**手持物品规则（MJ-CHAR-03）**：人物四视图**不得出现任何手持物品**（扫帚/拂尘/金箍棒/兵器等）；
双手自然垂落，或合十，或负手而立；只做"干净素模人设"。

**描述结构（MJ-CHAR-04，精简 3 大块）**：
- 角色名称 / 性别 / 年龄
- **整体形态**（优先级最高）：身形比例、体态气场、整体线条、服饰连贯性。
- **头部**（可写细，越多越稳）：脸型、五官、发型发色、眉形、眼部特征（用 MJ-CHAR-02 允许词）、神态气质。
- **上身**：衣着款式与颜色、面料质感、版型、领口肩型、袖口细节；双手自然垂落无手持物。
- **下身**：裤/裙款式、颜色、鞋子、整体垂感；尽量简单，一笔带过，避免比例崩坏与拼接感。

**构图标签（MJ-CHAR-05）**：`人物四视图，16:9 比例，正面全身、侧面全身、背面全身、面部特写，四格横向排列，背景纯白，人物直立静止无动作，无特效，无兵器，均匀柔和打光，光线明亮通透，无明显阴影，整体清晰干净，双手自然垂落无手持物品`。

**风格标签（MJ-CHAR-06）**：CG 动漫角色、非真人、虚拟形象、无肖像权问题；顶级影视级 CG 质感、OC 渲染、3d 仿真、超写实、电影感光影、史诗级构图、32k 分辨率、8k 纹理细节、3DCG 国漫风格；眼部按 MJ-CHAR-02；姿态直立静止，双脚与肩同宽，面部中性无夸张情绪。

**年龄标准（MJ-CHAR-07）**：少年 7-18 岁；青年 19-35 岁；中年 36-55 岁；老年 56 岁以上（也可用具体岁数）。

## 落盘映射（→ storyboard schema）

| 本表概念 | storyboard 字段 | 备注 |
