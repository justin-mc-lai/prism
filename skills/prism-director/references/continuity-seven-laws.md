## 1. 七律原文（Toonflow，一字未改语义）

| # | 名 | 原文规则 |
|---|---|---|
| ① | **动作连续性** | 相邻镜头间角色的位置、动作进度、朝向必须物理逻辑一致。上一镜手伸到半空 → 下一镜必须从半空状态接续，不能突然收回 |
| ② | **景别递进法则** | 渐进聚焦：远→全→中→近→特（情绪收紧）；渐进释放：特→近→中→远（情绪释放）。禁止无叙事理由的连续同景别（**连续 3 镜以上同景别 = 视觉疲劳**） |
| ③ | **视轴守恒** | 180 度线原则——对话/对峙场景中角色画面位置**全片固定同侧**，不得跳轴 |
| ④ | **朝向空间逻辑** | 对话双方面朝彼此，操作物品面朝物品，注视远方面朝远方。**禁止无差别面朝镜头** |
| ⑤ | **信息控制意识** | 每镜须意识到「观众此刻知道什么、不知道什么」——给手不给脸 = 悬念；先声后画 = 期待；只给背影 = 疏离；全貌揭示 = 高潮兑现 |
| ⑥ | **节拍密度约束** | 1 个物理动作 = 1 拍，1 次运镜 = 1 拍，1 句短台词（≤10 字）= 1 拍。**2~3s 最多 1 拍；4~6s 最多 2 拍；7s+ 最多 3 拍**（**上限**，防塞太多） |
| ⑦ | **头尾安全区** | 每镜前 0.5s 和后 0.5s 为安全过渡区，**不放关键动作或台词起始点**；前 0.5s 用于环境建立或主体静态亮相，后 0.5s 用于动作自然收住（**时间轴**视角） |

## 2. 再诠释版本（ai-comic-studio，用于对照，勿混用）

同一套七律在 `ai-comic-studio` 里被改写为：

- ⑥ 节拍密度 **翻转为下限**：`2~3s 至少 1 拍；4~6s 至少 2 拍；7~9s 至少 3 拍；10s+ 至少 4 拍`，
  且「重写后 `[]` 段落总数**不得少于**重写前」
- ⑦ 头尾安全区 **翻转为帧差**：「startFrame ≠ endFrame，变化须收在同一景别内」
  （太小 = 没发生事；太大 = 画面跳），并禁首尾帧写运动动词
- ① 动作连续 **拆为两条铁律**：**因果时序**（准备动作 + 反应动作必须逐拍体现，时长不够压缩秒数、
  不删节拍）与 **触发-反应**（画面外事件触发时，第一拍必须是短促反应定格，首帧锁在反应瞬间）
- 新增导演前置四问：**Q0 集级色温弧**（冷→暖 / 暖→冷 / 冷→暖→冷 / 中性→极端→收回）、
  **Q1 单一视觉概念**、**Q2 核心反差对**、**Q3 主动排除**

## 3. ★ 关键分歧：两版在治相反的病

| | Toonflow（原版） | ai-comic-studio（再诠释） |
|---|---|---|
| ⑥ 节拍 | **上限**（最多 N 拍） | **下限**（至少 N 拍） |
| ⑦ 头尾 | 前/后 0.5s **时间**安全区 | 首帧/尾帧**帧差**安全区 |
| 在治什么 | 碎镜、超载、单镜塞太多信息 | 空洞、慢动作、一镜一句话 |

**用法**：先判断当前主要失败模式，再选一侧；**不得同时套用**（上限与下限会互相打架）。
两版都不是物理常数——换模型/形态须重测（同 `prompt-syntax.contract.md` §5 精神）。

## 4. 附则 A · 片段间过渡与连贯性（Toonflow 专项规则）

消灭片段切换的「跳跃感」，四法：

1. **动作的桥梁** — 相邻片段描述同一组人物连续动作时，**禁止动作在边界"冻结"再"跳转"**。
   前片段结尾 = 动作**起始态**，后片段首镜 = 该动作**进行时/完成时**。
   ❌ 片段A尾「他握紧剑柄。」→ 片段B首「他拔剑冲上前。」
   ✅ 片段A尾「手猛地握住剑柄，指节泛白。」→ 片段B首「利剑'锵'一声出鞘，剑身映出他因怒火而扭曲的脸。」
2. **情绪的接力** — 前片段结尾用**反应镜/眼神/微表情/肢体细节**为下一段情绪爆发铺垫；后段首镜承接并强化或反转。
3. **空间与视线的链接** — 换场时用**空镜、视线引导、延续的环境音**建立空间联系
   （例：室内争吵 → 人物愤怒看向窗外 → 接窗外暴雨空镜（雨声延续 0.5s）→ 叠化次日街市大全景）。
4. **台词与动作的黏合** — 前片段末尾的声音（关键词、摔门声）延续到后片段首镜，由下一个画面承接。

## 5. 附则 B · 拆分粒度与防冗余（Toonflow）

- **拆分粒度**：一个独立画面 = 一条分镜；约每 **50~100 字剧本对应 1~2 条分镜**。
  新起分镜条件：场景/地点切换、时间跳跃、镜头主体切换、景别明显变化、重要动作节点。
  不需新起：同画面内连续对话、表情微变或小动作。
- **定场防冗余**：每个新场景定场**最多 1~2 个镜头**，禁拆 3 个以上碎片。
  禁止「环境空镜→局部细节→人物到达」的冗余三段式；能一镜交代的不拆两镜。
- **导演思维自检**：真人导演会把相邻 2~3 镜合成 1 镜 → 说明拆得过细，应合并。
- **黄金 6 秒规则**：无台词镜头累计超 **6s** 未出现新信息（台词/动作/主体变化），观众注意力断裂。
- **一镜到底**：相邻镜头存在动作连续变化、同场景轻度位移或角度渐变时，可合一为连续运镜长镜头，
  **时长可突破单镜 6s 上限但不超过 12s**；标注运镜路径与起落幅。会提高抽卡难度，不滥用。

## 6. 与 Prism 既有原则的一致性（旁证，非新规则）

Toonflow 同文件另有两条，**与 `prompt-syntax.contract.md` §0 三层分离一致**，可作为外部旁证：

- **人物外观不进提示词**：服装、发型、长相交给图片资产（对应本仓 ref 层拥有身份锚点）
- **禁光影/色调描述**：`description` 不得出现 光/影/色温/色调/暖色/冷色/逆光/明暗；
  光影由引用的**场景衍生资产**承担（夜景版/雨天版/火光版）
  —— 与本表 §3 的 ⑦ 取舍相关：若采 Toonflow 口径，则主光不进分镜描述，
  与「帧描述五要素含主光叙述」的另一版本互斥，**须按形态择一并在项目内声明**。
