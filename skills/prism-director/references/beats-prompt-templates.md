# Beats 填写提示词弹药库（beats-prompt-templates）

> 内部参考：供 `prism-director` 在填写 `storyboard.json` 的 `shots[].beats[]` 时直接套用。
> 上游：`references/modes/treatment-director.md`（步骤 7）→ 本文件 → `references/drama-storyboard-spec.md`（MJ-* 门）→ `scripts/prompt_compiler.py`。

## ATTRIBUTION

蒸馏自微信公众号「AI 老漫」《原来ai漫剧公司的导演是这样写提示词的》（作者 AI 老智，2026-08-13，

原文是"高手提示词"社区实践，非物理常数；换题材/换模型须重测。
本文件只做**字段映射**：把原文公式逐项落到 MJ-* 的 beat 字段上，不新增 MJ 规则。

## 1. 分镜运镜公式（每个 beat 一行）

```
[起始s-结束s]：[运镜方式]+[景别]+[主体人物描述]+[连贯动作链条]+[场景环境细节]+[分镜专属光影微调]
```

字段映射（→ `beats[]` 子镜字段）：

| 公式槽位 | beat 字段 | 备注 |
|---|---|---|
| `[0-Xs]` 时间段 | `duration_seconds`（2–5s）+ 起止由编译器累计 | MJ-UNIT-03 |
| 运镜方式 | `camera_move` | 见 §1.1，必须落在 MJ-CAM-02 枚举 |
| 景别 | `shot_size` | 见 §1.2，必须落在 MJ-CAM-01 枚举 |
| 主体人物描述 | `description` 前半 + `on_screen`/`blocking` | 在位人数与站位锁定（MJ-BLOCK） |
| 连贯动作链条 | `description` 主体 | 一个 beat 只写一个连贯动作，不跳切 |
| 场景环境细节 | `description` 后半 | 与 `scene_ref` 的场景一致 |
| 分镜专属光影微调 | `vfx` | 见 §4，每 beat 必填、非空 |
| 台词 | `dialogue`（≤30 字）+ `emotion` + `speech_rate` | 字/秒匹配情绪档 |
| 音效 | `sfx`（≤10 字、禁"无"） | 见 §5 |

### 1.1 运镜词库（原文 7 式 → MJ-CAM-02 11 式）

| 原文 | MJ-CAM-02 取值 |
|---|---|
| 固定机位（带轻微自然呼吸抖动） | 震颤（轻微） |
| 缓慢匀速向前推进 | 推 |
| 缓慢匀速向后拉开 | 拉 |
| 水平左右横移 | 移 |
| 垂直上下摇摆 | 升降 |
| 360° 缓慢环绕镜头 | 旋转 |
| 斯坦尼康跟拍 | 跟 |
| （原文无，MJ 补充） | 急推 / 急拉 / 摇 / 甩 / 推/急推 / 拉/急拉 |

### 1.2 景别词库（原文 5 档 → MJ-CAM-01 7 档）

| 原文 | MJ-CAM-01 取值 |
|---|---|
| 特写（面部 / 手部） | 特写 / 大特写 |
| 近景（胸口以上） | 近景 |
| 中景（腰部以上） | 中景 |
| 中全景（全身 + 近景环境） | 全景 |

### 1.3 示例：一个 10 秒分镜拆 3 个 beats（原文示例，字段标注版）

原文把一个 10s 镜头拆成 0–3s / 3–7s / 7–10s——这正是 MJ-* 要求的拆法：

- `0-3s`：固定机位（震颤），近景，24 岁清冷短发女生眼尾带泪痣、卡其色风衣，
  雨夜街道低头凝视掌心玻璃碎片、指尖微颤、雨水打湿发梢；
  光影：侧方冷蓝路灯打亮侧脸、暗部保留层次 → `vfx`
- `3-7s`：缓慢匀速向前推进（推），中景→面部特写，女生缓缓抬头望远处霓虹高楼，
  眼底落寞泛红、嘴角下垂，背景街灯虚化失焦 → `vfx`：浅景深虚化
- `7-10s`：缓慢向后拉开（拉），中全景→远景，女生独站混沌滩街道中央，
  渺小身影被巨大城市霓虹包围，雨水持续滴落 → `vfx`：雨效 + 霓虹反射

注意原文每段都同时给足**运镜 + 景别 + 主体 + 动作链 + 环境 + 光影**——
beat 的 `description` 达不到这个信息密度，就仍是"一句话分镜"，打回重写。

## 2. 全局基础画质前置词（→ 风格预设 / `[STYLE]` 层）

- 分辨率：8K 超高清院线电影级画质，超高细节纹理
- 摄影机：ARRI Alexa 65 大画幅电影机质感，动态宽容度拉满
- 镜头：50mm 标准定焦，f/2.8 浅景深，焦点锁定人物主体
- 胶片质感：柯达 5219 电影胶片，细腻自然颗粒，色彩柔和不锐化过度
- 制式：24fps，2.39:1 宽银幕画幅（竖屏漫剧按 `ratio` 9:16 换算构图）

## 3. 漫剧风格（→ 风格预设选择）

- 韩漫：manhwa webtoon 风格，清晰钢笔线条，平涂上色，分层柔和
- 日漫：吉卜力手绘风 / 新海诚光影风 / 赛璐璐复古风
- 国漫：东方水墨风 / 3A 游戏 CG 厚涂风

## 4. 影视光影 8 套（→ `vfx` / 光影微调槽位）

光影公式：`[主光源类型]+[精准色温]+[光线投射方向]+[辅光/轮廓光搭配]+[聚焦区域]+[明暗对比度]+[整体情绪氛围]`

| # | 名称 | 适用 | 打法（→ `vfx`） |
|---|---|---|---|
| 1 | 伦勃朗光 | 单人情绪 / 悬疑 / 文艺 | 单侧硬光主灯 + 弱辅光，脸颊三角光斑，后方窄轮廓光分离背景，色温 4200K，压抑伤感 |
| 2 | 蝴蝶光 | 甜宠温柔女主 | 正面高位柔光 + 下方反光板弱化暗部，色温 5500K，柔和低对比，治愈温柔 |
| 3 | 黄昏侧逆光 | 离别 / 黄金时刻 | 夕阳暖调侧逆光 3200K，强发丝轮廓光，正面低亮度柔光辅光，冷暖撞色，温柔伤感 |
| 4 | 三点柔光 | 日常居家 / 办公室对话 | 正面柔光主光 + 侧辅光 + 背部轮廓光，色温 5500K，明暗过渡平缓，松弛治愈 |
| 5 | 悬疑单硬光 | 密室对峙 / 惊悚 | 顶部单侧硬光，色温 4000K，无多余辅光，极高明暗对比，大面积深邃暗部，紧张压抑 |
| 6 | 蓝调城市夜景光 | 都市孤独戏份 | 天空冷蓝环境光 7000K + 街边暖黄辅光，伦勃朗光塑脸，冷暖对冲，孤独压抑 |
| 7 | 煤油暖黄光 | 夜晚室内离别戏 | 单盏煤油灯侧方暖黄主光 2600K，低亮度辅光提亮眼窝，面部伦勃朗三角光斑，厚重沉郁 |
| 8 | 赛博朋克对比光 | 霓虹都市 / 科幻 | 红蓝双色霓虹分侧对冲，混合色温，低亮度环境，高色彩反差，赛博氛围感 |

约束：`vfx` 每 beat 必填非空；资产 ref 层禁用戏剧光（见 `asset-prompt-templates.md` 两层分离），
光影只出现在分镜/视频层。

## 5. 音频设计公式（→ `sfx` + 音频要求行）

```
[持续环境音（音量 dB）]+[定点关键音效（出现时间 + 音量 dB）]+[背景音乐（曲风 + 音量 dB）]+[人声约束]
```

- 环境音库：持续雨声、晚风、街道车流杂音、室内安静底噪、森林风声
- 关键音效库：脚步声、开门声、纸张撕裂声、雨滴砸玻璃、金属碰撞、心跳声
- 背景音乐库：低沉钢琴独奏、舒缓弦乐、氛围感电子合成器、无背景音乐
- 落到 beat：`sfx` 只写**定点关键音效**（≤10 字，如"雨滴砸玻璃"），不写"无"；
  持续环境音与人声约束由分镜末行 `音频要求：不要背景音乐，不要字幕，不要解说声音。` 统一声明（MJ-FIELD-04）。

可直接套用的音频行示例：
`持续细密雨声（-12dB），2 秒处纸张撕开清脆音效（-6dB），全程低沉舒缓钢琴独奏（-18dB），无多余杂音，人声清晰突出。`

## 6. 全局硬性约束（→ `[NEGATIVE]` / 全局约束）

全程无超帧、无画面畸变扭曲、无多余空镜、无穿帮道具、人物口型与台词 1:1 精准同步；
无 AI 失真脸部，皮肤保留原生毛孔肌理，拒绝过度磨皮、重度美白；
人物四肢手部动作自然无畸形，五官脸型全程统一，服装发型配饰前后镜头无改动；
画面流畅无抖动、无闪烁卡顿、无崩坏肢体。
