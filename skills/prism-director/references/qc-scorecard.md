# Director QC Scorecard（Prism 蒸馏版）

> Internal reference for `prism-director`. Not host-discoverable.
> 蒸馏自 selfmedia-creator `skills/selfmedia-director/references/director-qc-scorecard.md`（自研）。
> 用途：导演方案交给写作/生成/渲染/发布前，先找弱意图、假冲突、超载变体、不可执行资产与不安全的事实/版权假设。

## 生产门

| 门 | 进入下一步前必须 | 通过证据 |
|---|---|---|
| treatment-approval | beat sheet、分镜、视觉生成 | treatment 有核心意图/受众/冲突/生产现实/non-goals |
| asset-continuity-approval | AI 图像/视频生成、重复角色工作 | 角色/场景/物件/风格 bible 完整到所选形态可用 |
| beat-sheet-approval | 脚本、分镜、剪辑方案 | beats 有注意力目标/情绪/剧情点/资产/转场/风险 |
| rough-cut-approval | 最终渲染 | 节奏、字幕密度、声音层级、缺失资产已审 |
| final-render-approval | 发布建议 | 最终产物经用户或明确负责人批准；禁止静默发布 |

用户只要早期创意概念时，停在 treatment 并把后续门标为 pending。

## 评分卡（每维 0–5）

| 维度 | 0 | 3 | 5 |
|---|---|---|---|
| 核心意图统一 | 无明确意图 | 有意图但变体漂移 | 每个元素服务一个意图 |
| 观众承诺 | 含糊「大家会喜欢」 | 受众点名、承诺泛化 | 受众与所得具体 |
| 冲突 | 只有话题 | 张力弱 | 具体失衡且有代价 |
| 视角一致 | 随机跳视角 | 大体稳定 | 视角与叙述者角色刻意设计 |
| 首个注意力窗口 | 问候/铺垫 | 有钩子但抽象 | 首拍有画面/冲突/矛盾 |
| 情绪曲线 | 平 | 有些起伏 | 积累/转折/证据/释放清晰 |
| 展示非说教 | 讲座式 | 混合 | 场景/细节/动作承载意义 |
| 视听意图 | 好看但游离 | 大体相关 | 镜头/声音/字幕都服务节拍 |
| 剪辑节奏 | 匀速 | 有些对比 | 时间被刻意拉伸/压缩/暂停 |
| 平台适配 | 通用输出 | 提到平台 | 形态与平台档案塑造呈现 |
| 资产可执行 | 假设不可得资产 | 缺失资产已标注 | 资产/版权/连续性可行动 |
| 事实安全 | 新增无据主张 | 大体有源 | 主张可溯源或标为创意 |
| 分发分离 | 发布与创意混在一起 | 大体分离 | 母稿/呈现/绑定/发布彼此独立 |
| 分镜颗粒度 | 每镜一句话描述、无子镜拆分 | 部分分镜有 beats 但字段不全 | 每分镜 5–8 子镜、六元组齐全、Σ时长=镜长（MJ-*） |

满分 70。

## 通过规则

- 60–70：对所声明门生产就绪。
- 50–59：可用但需具体修订，列出 top 3 修复。
- 40–49：概念可救但未达生产就绪，重写 treatment 或 beat sheet。
- <40：停下，先澄清意图/来源/素材。

自动阻断：

- 缺核心意图；
- 无目标受众；
- 无源或未标注的事实主张；
- 视频方案把未确认的素材/出镜当作既定事实；
- AI 生成真人形象无权利/同意处理；
- 暗示或承诺直接发布。

## 失败响应

1. 点名失败的门。
2. 给 top 3 失败原因。
3. 保留最强可用想法。
4. 给修订版最小 treatment 或 beat 修复。
5. 只问一个会改变下一版的关键决定。

不要用鼓励性语言掩盖低分——弱方案要早失败。
