## 0. 三层分离（先分层，再写提示词）

| 层 | 拥有什么 | 禁止 |
|---|---|---|
| **资产 ref 提示词** | 身份锚点、造型、材质、中性光 | 禁戏剧化情绪词、禁镜头语言、禁剧情（污染 ref → 每个下游镜头都偏） |
| **分镜图提示词** | 构图、机位、景别、光、本镜动作 | 禁重描 ref 已有的身体/脸部特征（重描 = 与 ref 打架）；禁剧情解释 |
| **视频段提示词** | 动作、表演、摄影、声音、起止状态 | 禁新增资产事实；禁不可见心理活动 |

跨层复用是失败主因：ref 层写氛围 → 一致性掉；分镜层写身份 → 与 ref 打。**同一条事实只在一层声明。**

## 1. 镜头提示词字段定式（文本/口播链）

字段顺序固定（`short-drama-skills/skills/05-单视频提示词润色`）：

```
镜头N，【时长】x秒
【主体】【场景】【核心动作】【台词】【镜头语言】【光影/滤镜】【动态场景/环境特效】
```

| 字段 | 必填 | 规则 |
|---|---|---|
| 【时长】 | 是 | 按 §3 公式算，冲突取大，封顶 §3 上限 |
| 【主体】 | 是 | `<角色名> + 动作+表情+道具交互` 合并成**一个逗号长句**；禁用代词/「同上」；陪体紧接 `, <陪体名> + 动作` |
| 【场景】 | 是 | 地点+时间（「夜晚的巷道」），须与原文语义一致 |
| 【核心动作】 | 是 | 视觉化替换平淡动作，1–2 句 |
| 【台词】 | 是 | **逐字填入，禁改写/删减/翻译**；无则写「无」 |
| 【镜头语言】 | 是 | 角度（平视/仰拍/俯拍/越肩/POV）+ 节奏（慢推/快切/闪切）；禁含糊 |
| 【光影/滤镜】 | 否 | 方向+色调+质感；与剧情无关则省略 |
| 【动态特效】 | 否 | 物理动态或小特效；音效标 J-cut / L-cut；无则「无」 |

正文尾句（逐字保留）：`严格按照分镜脚本进行生成，参考上传图的人物形象、场景和道具。不要生成字幕。`

## 2. 分镜图 8 段定式（出图链）

`onlyshot/references/storyboard-frame-industrial.md` 的 8 段，顺序即权重：

| 段 | 写什么 | 反模式 |
|---|---|---|
| `[CHARACTER]` | `(@ref.png) — same identity, 位置` | 全写 `same character identity`（浪费字符） |
| `[BACKGROUND]` | `soft bokeh: 1 <剪影> , N chibi silhouettes blurred` | 长句 `in deep bokeh background all out-of-focus` |
| `[ACTION]` | **拟物动作**：`tower leans / sphere glows / antenna pulses` | 人形动作 `stands center / hand-in-hand / raises arm` |
| `[SCENE]` | 前景道具 + 中景元素 + 背景地标 + `shallow DoF` | 堆抽象词 |
| `[CAMERA]` | 景别 + 角度 + 焦段 mm | — |
| `[LIGHT]` | 主光方向 + 边缘光 + 体积光 + 粒子 | — |
| `[TEXT]` | 字幕 1 处 + 弹幕写单数 `ONE bullet chat` | 同字幕重复 N 次（污染） |
| `[STYLE]` | 风格串 + **每个主角单独**写 `NOT a human wearing X` | 复数共用 `characters ARE X and Y`（模型不认） |

## 3. 时长与阈值表

**时长公式**（`short-drama-skills/.../01-通用叙事拆解`）

| 镜头类型 | 公式 / 时长 |
|---|---|
| 对话·常速 | `round(字数/8) + 1s` |
| 对话·争吵/紧迫 | `round(字数/10) + 1s` |
| 对话·亲密/遗言 | `round(字数/5) + 1s` |
| V.O. 旁白 | `round(字数/7) + 1s` |
| 微动作 / 常规动作 | 2s |
| 复杂连续动作 | 4s |
| 强烈情绪震荡 | 3s |
| 环境空镜 / 静物 | 2s |
| 慢动作（关键终结技） | 3–4s |

**硬阈值（可校验，任一违反即回退）**

| # | 阈值 | 来源 |
|---|---|---|
| 1 | 单镜**≤12s**（动作戏 ≤15s），含台词+动作取大值 | 01 / 03 |
| 2 | 静帧不得停留 **>6s**，超出立即拆子镜 | 01 |
| 3 | 长对白预估 **>8s** 必须拆（保留每个字，只拆节奏） | 01 |
| 4 | 单个 beat 内非叙事空镜/转场 ≤ **20%**，超出优先删空镜 | 01 |
| 5 | T1 正面说话镜 ≤ **60%**；T2 反应镜不得连续出现 2 次 | 01 |
| 6 | prompt 字符数 < **1500**（即梦 5.0），理想 1200–1400 | onlyshot（N=8 实测） |
| 7 | 长 prompt 与并发不可兼得：长 prompt 用 `candidates=1` + 串行 | onlyshot（N=36 实测） |

## 4. 切镜触发条件（不需要理由时不切）

切镜 = 有新信息。**没有新信息的切镜是废镜。**

必切：
- 地点变 / 时间跳 / 站位或权力关系变
- 权力转移（信息优势反转、立场改变、关系重定义、情绪控制权易手）
- 情绪突变 → 特写；情绪渐变 → 景别递进（**禁横切**）
- 动作方向重大逆转 / 武器损毁更替 / 受重创 / 场景转移

必不切（优先镜内调度）：
- 仅有动作方向改变、站位交替

## 5. 动作戏语法（`short-drama-skills/.../03`）

- **关键动作三段式**：动机/预备 → 执行 → 结果/反馈（普通过招可压一镜）
- **动接动**：切点落在运动轨迹**进行中**（刀抬到半空 → 切 → 挥下一半），不能落在动作完成后
- **物理反馈强制**：攻击必有受力位移/身体变形/物碎；同框反馈（常规）或受击方特写（重击）
- **位移闭环**：奔跑跳跃优先动态跟拍合并起步-过程-抵达；仅跨极大空间或强调落点才拆
- **节奏分层**：慢 → 快 → 更快 → 突停 → 再爆发；爆发段后给 2s 缓冲对峙
- **独占镜头**：金手指/底牌触发、关键反杀、第一滴血、武器亮相、角色首次爆发
- **受伤视觉确认**：写受伤就必须有伤口镜头，**禁只用表情代替伤害**
- **禁纯对话对打**：不允许两人站定对骂 >5s；须动作伴随或冲突后静默面部特写
- **群体打斗（3 人以上）**：分主线对抗/辅助干扰/远处威胁，焦点只能一条动作线
- **动势压迫**：被压制时降机位（仰拍施压者）或升机位（俯拍被压者），**禁平视表达失衡**
- **网文设定强制视觉化**：系统提示/面板/结算必须独立镜头做悬浮 UI 光幕特写
- **情绪反应镜**：受击方或旁观者的微表情（狂妄转惊恐）必须分配镜头

## 6. 对话戏语法（权力博弈，`short-drama-skills/.../02`）

核心前提：对话拆分围绕**权力流动**，但权力与情绪**必须转为摄影机可见的具象画面**。

| 规则 | 执行 |
|---|---|
| 权力变化触发切镜 | 权力上升者 → 微仰拍 + 特写；下降者 → 微俯拍 + 反应特写；群体压迫 → 前景遮挡 |
| 信息单位拆分 | 拆分单位 = 信息 beat（一个事实/态度/指控/反问/决定），**非一整句台词**；一句多信息必拆 |
| 反应优先 | 反应镜重要性 ≥ 说话镜；禁止「面无表情看着对方」 |
| 节奏断点 | 倒水/点烟/走位/拉开距离/站起/转身/掏道具；动作改变空间关系 → 必切 |
| 视角递进 | 中景 → 过肩 → 近景 → 特写 → 极近特写（**高潮时禁停在中景**） |

反模式：连续「平视中景A ↔ 平视中景B」乒乓。

## 7. 五条视觉转化规则（`01`）

1. **台词具象化** — 提到过去具体事件就插闪回，别只拍说话特写
2. **潜台词外化** — 抽象情绪变可见动作：「焦虑」→「反复抠衣角，指甲发白」
3. **无想象动作缺口** — 忠实原动作，状态跳跃必须补过渡动作，禁瞬移
4. **锁定视点** — 剧本未明说不得自行换地点；画外音出现时焦点给**在场听者反应**
5. **关键信息特写** — 任何推动剧情的道具独占近景，禁埋在远景

配合 T1–T7 技法（正面说话 / 反应 / 道具细节 / 闪回象征 / 景别递进 / 动作伴随 / V.O. 换画）。

## 8. 提示词卫生（失败模式，`onlyshot/references/jimeng-failure-modes.md`）

**先分三类 fail，再修**（混修 = 白跑）：
- 内容审核 fail → 改词（不是改长度）
- 字数 fail（`ret=1046 InvalidNode`）→ 压长度
- 限流 fail → 降并发

敏感词四类（出图生成失败根因）：① 反派/邪恶词 ② 暧昧/亲密词（面部特写尤易触发）③ 中文敏感词（字幕/弹幕段）④ 街拍/真人拟人词。

ref 层三个硬伤：
- **多 ref 同框 = 一致性必崩**（拆单人或换构图）
- **prompt 重描 ref 已有身体 = 污染 ref**
- **ref 库本身偏置无解**（模型侧救不回，只能重做 ref）

视觉指纹（风格锚点）**放在 prompt 开头**（最高权重），布局/负面放末尾。

## 9. 反向禁项清单（写提示词时逐条排除）

- 禁抽象质量词：`golden ratio composition` / `negative space` / 「精致」「高级」
- 禁代词与「同上」指代主体
- 禁改写/翻译/删减台词
- 禁生成字幕（除非明确要 TEXT 段）
- 禁「面无表情」类空表情
- 禁人形动作描述拟物角色
- 禁把镜头瞬态（姿势/视线/左右手/角度）写进资产层
