## 0. 三模板的分工（别混层）

| 模板 | 粒度 | 拥有什么 | 不拥有 |
|---|---|---|---|
| **完整剧本** | 全集/整季 | 世界观、大纲、分集概要、钩子、卡点、付费点 | 单镜画面、提示词 |
| **分集剧本** | 一集 | 冷开场、逐段画面+对白+潜台词+音效、对白汇总、节奏自查 | 出图提示词 |
| **镜头清单** | 一镜 | 镜号/时间/景别/运镜/角度/角色/动作/对白/氛围/音效 | 重写剧情 |

**改编粒度换算（上游 → 本仓）**：上游按 `36 grid × 4-10s = 180s` 排；
本仓 manga_drama 为 `8-12 shots × 60-90s`（`storyboard-schema.json`）。
本表保留上游字段语义，数量按本仓规格收缩；**不要照搬 36 格**。

## 1. 完整剧本模板（全集级）

```markdown
# 《<作品名>》完整剧本

## 作品信息
- 项目编号 / 流派 / 题材原型 / 基调 / 目标受众
- 总时长：<N 集 × M 秒>
- 核心主题：<一句话>
- 核心钩子：<>
- 重复爽点公式：<>

## 世界观设定
<200-300 字；现代题材也要写社会背景与人物关系土壤>

## 故事大纲（起承转合）
- 起（第 A-B 集）：<125 字>
- 承（第 C-D 集）：<125 字>
- 转（第 E-F 集）：<125 字>
- 合（第 G-H 集）：<125 字>

## 各集概要
### 第 N 集：<标题>
- 剧情概要（≤50 字）
- 关键事件：<>
- 本集核心钩子：<>
- 结尾卡点：<>
- 情感强度：<>/10
- 是否付费点：是/否
- 节奏类型主导：<钩子重/反转重/爽点重/虐点重>
- 完整出稿：是/否

## 付费点布点
| 卡点 | 集数 | paywall_punch（具体反转） |
|---|---|---|
| 一卡 |  |  |
| 二卡 |  |  |
| 三卡 |  |  |
```

**规则**：一次剧本只拥有一个核心主题；钩子/卡点必须具体到"观众看到什么"；
集数上限按产能定，超了先砍（成本 + 观众记忆）。

## 2. 分集剧本模板（集级）

```markdown
# 第 N 集：<标题>

## 集信息
- 视频编号 / 时长 / 节奏类型主导
- 本集核心钩子：<一句话>
- 结尾卡点：<一句话>
- 是否付费点：是/否
- 涉及角色：<characters[].id>
- 涉及场景：<scenes[].id>
- 涉及道具：<props[].id>

## 冷开场详写（0-3s）
> 逐帧写画面 + 声音。例：
> 0-0.5s 黑屏 + 拐杖叩地一声
> 0.5-1.5s 镜头亮起，面部大特写
> 1.5-3s 第一句台词（钩子）

## 逐镜详写
### shot-01（0-7s）
**画面**：<人物动作 / 表情 / 运镜>
**对白**：
> <角色>[语气]：「<台词>」[节奏标记]
**潜台词**：<表面 X，潜台词 Y>
**音效 / BGM**：<具体配方>
### shot-02（7-14s）
[同上结构]

## 卡点详写（最后 10s）
> 镜头 / 对白（半句被切断）/ 视觉（黑屏/定格/静帧+文字）/ 音效

## 本集对白汇总（给配音/字幕用）
| 序 | 时间 | 角色 | 台词 | 语气 | 潜台词 |
|---|---|---|---|---|---|

## 本集节奏自查
- [ ] 0-3s 钩子够强？
- [ ] 30 秒有第一爆破点？
- [ ] 平均每 3s 有动作/对话/反应？
- [ ] 每分钟 ≥3 个情绪爆点？
- [ ] 至少 1 次 satisfaction？
- [ ] 卡点够狠？
- [ ] 每句台词够短？（口播 ≤15 字/句为上游口径，按本仓形态重测）
- [ ] 没有内心独白（改为可见动作）？
- [ ] 连戏标记齐全？
```

**与提示词的接口**：`对白` 逐字进分镜的 `dialogue`，编译时**禁改写/翻译/删减**
（`prompt-syntax-table.md §1`、`§9`）。潜台词只用于表演，不进提示词正文。

## 3. 镜头清单模板（镜级）

```markdown
# 第 N 集 镜头清单

视频编号 / 时长

| 镜号 | 时间 | 景别 | 运镜 | 角度 | 角色 | 动作 | 对白 | 氛围 | 音效 | 图片提示词简版 |
|---|---|---|---|---|---|---|---|---|---|---|
| shot-01 | 0.0-7.0 | 特写 | 慢推 | 俯视 |  |  | — |  |  | <一句话> |
| shot-02 | 7.0-14.0 | 近景 | 固定 | 平视 |  |  | 「」[钩子] |  |  |  |
```

**配套两张检查表**：

```markdown
## 连戏检查（剪辑时交叉验证）
- 服装：<每个角色本集穿什么>
- 道具：<关键道具状态 / holder>
- 场景：<灯光/陈设状态 / variant>

## 景别分布检查
| 景别 | 镜数 | 占比 |
|---|---|---|
| 大特写 / 特写 | / N | 上游推荐 ≥50% |
| 近景 / 中景 | / N | 上游推荐 ≤40% |
| 全景 / 远景 | / N | 上游推荐 ≤10% |
```

> 分布比例为上游单项目口径，**非物理常数**；按本仓形态重测后再引用。

## 4. 分镜数据结构（落 `storyboard.json`）

上游用独立 `分镜.json`；本仓统一落 `content/pipelines/ai-manga-drama/storyboard-schema.json`
的 `shots[]`，字段映射：

| 上游字段 | 本仓 `shots[]` | 说明 |
|---|---|---|
| `grid_number` | `shot_id` | `shot-01` 形式 |
| `_duration` | `duration_seconds` | 单镜 ≤12s（`prompt-syntax-table.md §3`） |
| `scene_description` | `description` | ≥10 字符 |
| `camera.{type,movement,angle}` | 进 `description` 的镜头语言段 | 编译时按 8 段落位 |
| `characters[].action/expression` | 进 `description` | 资产层不重描身份 |
| `dialogue.text` | `dialogue` | 逐字 |
| `characters_in_episode` | `characters[].id` | + `ref_image` |
| `scenes_in_episode` | `scene_ref` | + `ref_image` |
| `props_in_episode` | `prop_refs` | + `ref_image` |
| `first_frame_path` | `ref_image`（shot 级，可选） | 缺省回落 `asset_ref` |
| `video_mode` | 不落 schema | 编译进视频提示词 |
| `jimeng_prompt` | **不手写** | 由 `prompt_compiler.py` 生成 |

**禁止**手写 `jimeng_prompt` 类成品提示词进 storyboard —— 那是编译器产物，
手写会绕过资产门与语法门（见 `contracts/asset-render.contract.md`）。

## 5. 硬边界

- 不复制上游运行时（`scripts/*.py`、`tools/`）；不搬上游样例正文。
- 上游数量/比例阈值（36 grid、50%/40%/10%、≤15 字/句、180s）为**单项目口径**，
  换形态/模型须重测；引用带来源与测试条件，未重测即引用视为无证据。
- 剧本/分镜落盘后**必须人可改**（markdown/json），不得只存在对话里。
- 不新增剧本没有的实体；含混指代标「未决」，未决项不得流入提示词（同 AST-05）。
- 本表**不**出图、**不**编译提示词、**不**判 QA；那是 `prompt_compiler.py` 与 `prism-qa` 的事。
