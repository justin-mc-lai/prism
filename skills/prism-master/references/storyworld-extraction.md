# 剧本 → StoryWorld 资产提取（distill · drama-skills）

> 蒸馏源：`vendor/skills/drama-skills/skills/short-drama-assets`（MIT，zenstory-ai/drama-skills；
> 授权登记见 `docs/ATTRIBUTION-bridges.md`）。只取判断框架，不复制运行时。
> 与 `skills/prism-director/references/asset-consistency-gate.md` 分工：
> **本表管「从剧本抽出哪些资产」，资产门管「抽出来之后跨镜是否一致」。**

## 1. 何时用

拿到一部小说/剧本/大纲，需要先得到可复用的**资产清单**（人物 / 场景 / 道具）时。
产出喂两个下游：StoryWorld（`contracts/storyworld.schema.yaml`）与分镜
（`content/pipelines/ai-manga-drama/storyboard-schema.json` 的 `characters` / `scenes` / `props`）。

**不适用**：定稿正典、写镜头、生成媒体。

## 2. 先分四层，再决定动不动笔（核心）

| 层 | 定义 | 归属 |
|---|---|---|
| **身份** | 换一个就不再是同一个人 / 地 / 物 | 建资产条目 |
| **变体** | 身份不变，服装 / 伤势 / 时段 / 天气 / 开合 / 持有状态改变 | 记基底 + 变化 + 原因 + 生效范围 |
| **镜头瞬态** | 姿势、视线、左右手、站位、机位 | **归分镜**，资产层只引用 |
| **故事语义** | 知识、目标、关系、情绪 | **归写作**，资产层只引用可见后果 |

**禁止**把每次出场都变成新身份；含混指代标「未决」，**不猜**。

## 3. 三类资产的字段形状

| 类 | 对应 schema 字段 | 必填 | 说明 |
|---|---|---|---|
| **人物** | `characters[]` | `id` `name` `traits` | `traits` 写身份锚点；`voice_id` 供 TTS 选用 |
| **场景** | `scenes[]` | `id` `name` `kind` `traits` | `kind` ∈ `interior`(内景) / `exterior`(外景)；时段/天气写 `variant`，**不新建身份** |
| **道具** | `props[]` | `id` `name` `traits` | `holder` 填 `characters[].id`；**换手即换 holder**，不新建道具 |

`id` 统一 `^[a-z0-9][a-z0-9-]*$`，全集只用一个拼写，大小写一致。

## 4. 提取步骤

1. **只读**当前范围的剧本 + 已决定的视觉方向，先不创建任何资产。
2. 逐场扫实体、可见描述、状态变化、含混指代。
3. 对每一项判定：**新建 / 复用 / 加变体 / 标未决**（四选一，不跳）。
4. 写**最小可识别设定**：先写「什么不变使它仍是同一资产」，再写本集变化。
5. 检查造型与伤势、持物与所有权、道具状态、场景时段与天气、跨集 outgoing。
6. 末端一次回报：关键身份决定 + 真实未决项。

## 5. 三条写作规范

- **识别锚点**：必须**可见、可生成、可比较**；不用「精致」「高级」等空泛质量词替代事实。
- **连续性锁**：只给「跨镜出现且观众看得出不一致」的可见事实加锁；锁面用提示词语言写成
  **最小名词短语**（例：`olive-green stand-collar service dress`），会变的部分留给变体。
- **画面代称**：提示词正文语言不是中文时，人物条目必须给出一行 `画面代称：<正文拼写>`；
  正文从不点名它时写 `画面代称：无`。名字与常用词同形（道具「手机」撞「手机店」）也写 `无`。

## 6. 硬边界

- **不猜含混指代**——标「未决」，等证据。
- **不抢剧本语义**——知识/目标/关系/情绪不搬进资产，只引用可见后果。
- **未决项不得流入分镜**（fail-closed，同 `asset-consistency.contract.md` AST-05）。
- **不新增剧本没有的实体**；不做授权判断（授权属 `contracts/adaptation.contract.md`）。

> 抽出来之后**资产 ref 提示词怎么写**，见
> `skills/prism-director/references/asset-prompt-templates.md`（7 段 identity block +
> 五类资产卡：人物/场景/道具/神兽/群像）。本表管「抽哪些」，该表管「怎么写成提示词」。

## 7. 完成判据

所有明确出场都已「复用 / 新建 / 变体化 / 标为真实未决」四选一落地；
需要保持的可见事实与状态变化已写入资产条目。
**图片提示词、分镜、审查、生产不自动开始**——那是下游面的事。
