# 说人话层（human-voice-prose · Prism 蒸馏版）

> Internal reference for `prism-produce`. Not host-discoverable.
> 蒸馏自 selfmedia-creator `skills/selfmedia-writing/references/human-voice-prose.md`；
> 上游：ra-人话（vendor）+ human-writing 1.1.0（MIT，KKKKhazix / 数字生命卡兹克），
> 范本：《开源「活人感写作.skill」》（卡兹克 X 长文）。
> 定位：覆盖所有公开成稿的**文笔/改稿层**。执行顺序：prose-core 定结构与底线 → 本层定人味 → 个人文风层（`personal-style-layer.md`）定「像谁」→ humanizer-zh 族终检。

## 第一性原理

AI 味的根源不在句式，在「一篇文章什么都有，可唯独没有一个真实的人在里面生活过」。

活人感三个来源，按优先级：**材料 > 说话位置 > 语气**。只改语气（删「不是而是」、换黑话）是在剥 AI 味的皮；材料、位置、判断不动，皮剥完里面还是空的。

本层是三道门：**材料门 → 位置门 → 禁令门**。禁的永远是**修辞动作**，不是字面。

## 0. 材料门（动笔前，现实稿硬门）

非虚构长稿（计划 ≥1200 字）先在内部列出 **≥5 件具体材料**，注明来自用户哪句话或哪份可靠来源。只写概括性类别不算；5 件材料还要能组成一条实际过程，不能是 5 句相邻的道理。

材料不足时三选一：

1. 事实型题目有公开材料可查 → 先研究，研究后重新计数。
2. 个人体验/私人判断缺材料 → 一次问完 ≤3 个问题，此时不交稿。
3. 不许追问且研究后仍不足 → 缩小题目，宁可交 600 字短答，不能注水。

禁止用以下东西撑篇幅：模型临时想出的「比如有个人」、没有来源的典型场景、常识推演、抽象观点的后果、比喻与同义改写。三条抽象想法怎么解释都是三条，不是五件。

虚构稿不受来源约束，但每个主要场景必须有目标、动作、变化或选择；只换景色和说法不算发生事情。

## 1. 说话位置（动笔前五问，答案留在后台）

1. 谁在说这件事，他凭什么知道，哪些地方只是推测。
2. 什么事情让他现在想说（一条新闻、一次经历、一个一直想不通的小事）。
3. 手里有哪些能托住文章的东西——优先动作、数字、时间、地点、原话、失败、代价、后来结果。
4. 他对哪一点有明确判断，依据是什么，判断到哪里为止。
5. 读者读完上一段，最自然会追问什么。

没有亲历不写亲历，但作者不必消失：可以说自己更信哪种解释、哪条材料改变了自己、哪个流行说法让自己觉得不对。声音来自取舍，不来自「我觉得」「说真的」「大家想想」这类代词。

## 2. 推进规则

- 开头尽快碰到事情：直答、刚发生的一幕、反常的小事实都行；不预告全文结构。
- 一段先完成眼下这一件事：动作、背景、算账、解释、承认疑点或下判断。
- **新段落必须增加一件新东西**：新事实、新动作、新例子、新区别或新后果。同一观点换说法不算推进。
- 后一段接住前一段留下的问题；推进靠材料和因果，不靠「更深一层」「真正的问题」这类路标。
- 分类来自材料，不拿分类代替文章。除非用户要清单/教程，不要先把题目命名成「两个成本、三层原因、四个阶段」。
- 知识在需要它的地方出现：一段背景若能解释人物为什么只能这样选、能改变风险大小、能推翻直觉，就放进来；只证明作者知道很多，删掉。
- 岔话要从眼前的词长出来，回来时要多带一件东西（证据、尺度、反例、承认想错）；出去一圈判断纹丝不动，就是知识展览。
- 判断可以偏、可以有情绪，把依据放在附近。材料支持七成就说七成，剩下三成承认不知道，比补五个限定词可信。

## 3. 中文词序与停顿

- **主干早出**：先让主语和动作出现，再往后接时间、原因、条件和例子。连续三个「的」或读到名词已忘句首，就拆开。
- **顺着动作往后长**：前一句把新东西送到句尾，下一句接住它。指向清楚时省掉重复主语和机械连接词；两三个人同时在场时把名字写回来。
- **白话打底**：「买/购买」「改/修改」「看/观察」按说话者和场合选，不整篇换成长词，也不为古意硬压单字。成语典故三条件同时成立才留：意思准确、普通读者不用查、放进去比白话更省。典故需要另起一句解释，说明它没真正进入文章。
- **停顿有轻重**：读出声。逗号处还能接着说，句号处已落下一件事。连续短句像敲桌子就合并；长句一口气没有落脚处就拆开。
- **动作后面少解释一句**：动作、物件、原话、比喻已传出情绪就停。「老周把药分进七个小格，走到门口又回来把星期三那格打开看了一遍」已经够了，不要再补「他很担心」。
- 段落不必等长，普通地方用普通句子结束；单句成段只留给确实需要停一下的地方，不能连续排成口号。
- 同一个关键词可以重复；为躲重复频繁换同义词，文章会变油滑。
- 幽默来自降格：宏大说法碰到现实小麻烦的落差，写出来就够；笑点落下后继续讲事，不解释为什么好笑。

## 4. 翻案腔（核心禁令：禁动作，不禁字面）

**定义：** 先立一个读者并没有的误解，再推翻它给下文抬价。这是 AI 最典型的「姿势」，换成任何字面都是同一件事。

| 外衣 | 例子 |
|---|---|
| 字面翻案 | 不是A，而是B。并非A，而是B。不在于A，而在于B |
| 省字变形 | 不是A，是B。不是A，B才是 |
| 跨句变形 | 不是A。而是B。表面上是A。其实是B |
| 换字变形 | 与其说A，倒不如讲B。与其说A，毋宁说B |
| 以为体 | 你以为A，其实B。我一直以为A，后来才发现B。回头才发现 |
| 让转体 | 看似A，实则B。大家都说A，可真相是B。答案恰恰相反 |
| 抬价体 | A不重要，重要的是B。真正值钱的从来都与A无关 |

**拆除方法只有一种：** 找到这句话原本想下的判断，从正面把它说出来，再把依据放在旁边。不要寻找另一种漂亮句式替换。

**何时允许：** 文章真的用材料走过了从误解到修正的过程，可保留一次自我修正，但不能穿上面任何一件外衣。原文引语命中禁令时改成转述或省略，不能靠引号保留。

## 5. 硬禁令清单（命中即改）

1. **破折号**（`—`/`--`/`–`）正文清零。
2. **冒号**只允许一种用法：引出人物直接原话。「一句话总结：」「核心是：」这类提示性冒号禁止。
3. **三项以上同构排比**：整齐克制服两项为限，第三项换说法或删掉。
4. **抽象名词配具体动词**：时间不会保管细节，焦虑不会显出形状。还原成人做了什么、发生了什么。
5. **动词名词化**：「完成了对流程的优化」写成「把流程改顺了」；「实现了效率提升」写成「快了多少、省了几个人」。
6. **硬停词**：说白了、说穿了、先说结论。
7. **洞察路标**：更微妙的是、还有一层、只说对了一半、值得注意的是、需要指出的是、从某种意义上说（本义用法除外）。
8. **绝对黑话**：赋能、抓手、商业闭环、价值闭环、能力沉淀、拉通、底层逻辑、顶层设计、认知跃迁、价值释放、能力建设、降本增效、内容矩阵、全链路、组合拳、打开想象空间、结构性机会、关键命题、深层逻辑、技术底座、公共底座、技术主权、单点风险、主脊柱、材料锚点、认知增量、迭代闭环。
9. **语境黑话**（只在本义时保留）：沉淀、颗粒度、对齐、协同、链路、生态位、心智、范式、方法论、核心变量、打法、想象空间、闭环。
10. **借喻包装抽象**：非虚构内容不用仓库、抽屉、温度、死亡、坍塌、浪潮、钥匙、底座等给抽象概念穿衣服（真的在写这些东西时不受影响）。
11. **抒情词抽象化**：安放、抵达、微光、褶皱、丰盈、滚烫、轻盈、赤裸、剥开、锋利、坚硬、柔软——写具体事物时是好词，给抽象概念穿衣服时删。「」自造短语一篇 ≥3 处，多半在造金句，拆掉。
12. **补充禁令**：命令式开头（别急着X先Y）、伪洞察标记（真正/其实/本质上/关键在于/最重要的是）、冒号讲义腔、模糊指代（东西/这件事/这些）、时态错位（把已完成的写成「我会用」）、空泛比较（更适合/更像）、抽象压力句（差距会突然变得很难看）、空泛总结收尾。

## 6. 体裁裁决表（冲突时怎么执行）

| 体裁 | 翻案腔/否定壳 | 检查脚本 | 说明 |
|---|---|---|---|
| oss-pick-standard / daily | 零容忍 | 硬失败 | 科普走正面陈述，prose-core 第 5 条 |
| 公众号贴图 caption | 零容忍 | 硬失败 | 短行分点，禁金句收尾 |
| emotional-essay | 「新区分」检验放行：完整壳 ≤4 次，独立「不是…。是…。」配对可多 | 命中项作提醒，人工过判别开关 | 否定定义是引擎，见 emotional-essay 判别 |
| 口播/卡兹克体 | 自然说话式修正允许 ≤2 处 | 提醒 | 以「说话动作是否真实、是否带新材料」判断 |
| novel/连载（kushi 叙事） | 破折号：允许但「过度」即删；翻案腔：感知修正式（人物从误解到认知变化的叙述动作）逐处过「新区分」检验 | 命中项作提醒，人工过判别开关 | 源仓口径：kushi-narrative-zh「删过度破折号」；Prism 操作口径：单篇 >15 处或密度 >1 处/150 字视为过度；每篇感知修正式翻案腔 ≥5 处需删减 |
| 引用/转述 | 原话命中改转述 | — | 不能靠引号保留违禁句 |

**脚本-体裁仲裁：** `check_human_voice.py` 的冒号/破折号失败项按此裁决——
结构性固定位豁免：Markdown 标题（`#` 行）、引文元信息（`> 库拾一句话：…`）、
占位符（`【截图占位 X：…】`）、小节标题（`## 🚀 小白 MVP：…`）、
列表引导（`项目地址：`、`直接在你的终端执行：`）属于形态契约固定位，允许；
正文叙述句中的提示性冒号（「一句话总结：」「核心是：」）仍硬禁。
豁免项必须在 humanize 证据中逐条列出「位置 + 归属固定位」，不能默认放行。

## 7. 改稿七遍（初稿完成后执行）

1. **谁在说**：圈出「换一个模型也能原样写出来」的段落，优先处理——补信息来路、作者取舍、具体材料，没东西可补就删。不要用「我觉得」「说真的」修复匿名感。
2. **文章怎么走**：给每段标主要作用（动作/事实/解释/例子/疑问/判断/背景/情绪）；连续几段只做同一件事就拖。做压缩试验：删掉 1/3 后事实、动作、判断几乎没变 → 原稿注水，保留删短版。
3. **拆表演性中文**：假深刻（单独截图好看、放回正文无用的句子删）；假具体（没有来源的精确时间/天气/神态/摆设/原话，现实稿删）；假口语（老铁/兄弟们/粗口/错别字/括号吐槽，不主动添加）；抽象名词（一句话能换进十篇商业文章，删）；比喻换场（短距离三套借喻全部还原成本义）。
4. **听中文**：主干早出；检查前一句把什么交给了后一句（「这/它/他们」认错人就写回名字）；停顿有轻重；动作后面少解释一句；白话古意不打架。
5. **清禁用项**：跑 `python3 scripts/check_human_voice.py <稿>`，失败项清零；提醒项按第 6 节裁决表人工处理。
6. **核现实/设定**：现实稿核时间、数字、身份、引语、因果、第一人称动作；虚构稿核人物知道什么、时间空间、因果与世界规则。
7. **查结尾**：把最后两段分别删掉再读，删掉更有力就让文章提前结束。最后一段重述全文，即使概括得漂亮也先删。搜「时代、文明、未来、世界、历史、奇迹、所有人、全人类」——正文没有持续处理这个尺度，结尾就回到具体事实、人物动作或当前判断。开头物件在结尾回来时，读者对它的理解必须已经改变。

## 8. 冷读终检（交稿前）

暂时忘掉所有规则，只回答：

1. 哪里让我相信作者确实知道这件事。
2. 哪里让我愿意继续读。
3. 哪一段像人在处理一个问题，哪一段像模型在完成写作任务。
4. 哪句话说得比材料大。文章在哪一句已经结束。
