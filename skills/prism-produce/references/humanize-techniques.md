## 改稿前：AI 套路信号扫描

| 信号 | 典型表现 | 处理 |
|---|---|---|
| 句长均匀 | 连续多句长度接近，节奏像流水线 | 拆短句；插极短判断 |
| 结构对称 | 三点并列、每点一句，像 PPT | 合并/删一点；一点展开成故事 |
| 万能开场 | 「在当今…」「随着…不断发展」 | 场景或结论开头 |
| 空总结 | 「综上所述」「具有重要意义」 | 改成具体下一步或删掉 |
| 排比成瘾 | 三个「不仅…而且…」 | 留一个，其余改碎碎念/反问 |
| 中性正确 | 全是正确废话，无取舍 | 补「我更在意…」「这招有坑…」 |
| 无主体 | 从无「我/你/我们」的具体立场 | 补视角 |
| 过渡词翻译腔 | 「此外」「然而」「值得注意的是」扎堆 | 换成口语转折 |

30 秒快检：

1. 任意三句字数是否差不多？→ 交错
2. 有没有一句像人会说的牢骚/犹豫？→ 补
3. 有没有只有你知道的细节？→ 补或占位
4. 结尾是不是空口号？→ 改成行动或留白

## 人味手法（写作时强制组合）

### 1. 句式长短交错

长句（条件/因果）→ 短句（判断）→ 反问 → 短感叹。同一段内至少两种句长量级。

反模式：连续多句「主谓宾 + 的 + 名词」说明书腔。

### 2. 转折与口语连接（点缀）

可用：其实 / 说真的 / 讲道理 / 话说回来 / 我倒觉得 / 先说结论 / 问题是…

密度：约 800 字内 3～6 处；禁止每句「说实话」。

### 3. 个人经历与细节

优先级：用户真素材 → 可核对公开事实 → `【经历占位：时间/场景/结果】`。

差：「我们提升了效率」。
好：「把推送从 120 字砍到 47 字，打开率才从个位数爬起来」。

### 4. 情感起伏

有态度、有过程（以为…结果…）、有边界（适合 A 不适合 B）。

### 5. 改写手术顺序

1. 删空开场与空结尾
2. 打散并列结构
3. 插入口语转折
4. 埋 1～2 个具体细节
5. 通读出声再拆别扭句

## 平台差异

- **小红书**：开头抓痛点；emoji 克制；分段短；标题要有正文兑现。
- **公众号**：可稍长；小标题宜问题句；结尾行动要具体。
- **口播/短视频**：按气口断句；前 3 秒钩子；少「进行、以及、从而」。
- **知乎/长文**：人味 + 信息密度；段落内仍要口语起伏。

通用：先像人，再像运营。

## 可复制：降套路提示词

```text
你是资深自媒体作者。请把下列素材写成可直接发布的中文正文。

硬性要求：
1. 生动口语化，像认真聊过这个领域的人在说话，不要报告腔、公文腔。
2. 句式长短交错：长句、短句、反问、感叹混用；避免连续多句长度接近、结构对称。
3. 适度口语连接与转折（其实、说实话、讲道理、话说回来、我倒觉得），不要堆砌。
4. 避免机械化排比、「首先其次最后」、「综上所述」、「值得注意的是」、「赋能/闭环/全面」。
5. 增加情感起伏：有判断、犹豫、取舍，不要只有正确废话。
6. 个人经历只用我提供的事实；没有则用【经历占位：…】，禁止编造。
7. 不要承诺「通过某检测」；不要输出检测分数。

素材/初稿：
<<<
（粘贴）
>>>

平台：（小红书/公众号/口播）
篇幅：（字数或秒数）
```
