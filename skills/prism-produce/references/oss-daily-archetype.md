# 日榜体裁（oss-pick-daily · Prism 蒸馏版）

> Internal reference for `prism-produce`. Not host-discoverable.
> 蒸馏自 selfmedia-creator `skills/selfmedia-writing/references/oss-daily-archetype.md`（自研）。

**不适用**四段式 🎯🗺️💎⚠️。读者仍是新手小白，但体裁是「今日 GitHub 什么在涨星」。

## 结构

1. 标题 + 当日合计涨星
2. **今日概览** — 1～2 段：今天大家在关心什么、谁该看
3. Trending 截图 + 图说
4. **今日榜单** — 表格（中文「它是干什么的」列）
5. **值得点进去看的** — 2～4 条段落展开
6. **读榜时几个词** — 榜内生词 3～5 句
7. 数据从哪来 + 收尾

长度：800～1200 字 + 表。

## 禁止

- 套用 🗺️💎 深度四段
- 跑 `oss-repo-read`（日榜不读仓库）
- 表格描述列贴英文 README 摘要（必须中文白话）
