# 标题实验室（title-lab · Prism 蒸馏版）

> Internal reference for `prism-produce`. Not host-discoverable.
> 语料依据：BigPengSays/bigpeng-hot-gzh（MIT，2026-08-18 核实）的 7 标题公式与 8 选题模板；
> 样本校准：`references/title-corpus.md`。署名与 LICENSE：`docs/ATTRIBUTION-corpora.md`。

## 定位

只做两件事：**选题方向**与**候选标题**。不写正文、不写大纲、不渲染。
正文交给 `form-produce`（writing.contract + prose-core + 人味层）。
本层是双路径：有草稿/想法走**路径 A**；只有关键词或没想法走**路径 B**。

## 路由

| 输入 | 路径 |
|---|---|
| 文章描述、草稿、明确主题句、或「帮我起标题 / 做几个爆款标题」 | A：只出标题 |
| 关键词、一句话想法、「写点什么好」「不知道写什么」 | B：先选题后标题 |

## 路径 A：已有选题 → 6 条候选标题

1. 读 `title-formulas` 结构（下表），需要校准时翻 `title-corpus.md`。
2. 抽可钩元素：对象工具、身份、数字、结果、冲突、代价、附赠物。
3. 从 7 公式里选 **6 个不重复公式**各出 1 条（情绪短句最多 1 条）。
4. 每条标注：公式 / 字数 / 为何可能点 / **正文必须兑现什么**。
5. 过标题门清单（`skills/prism-qa/references/anti-slop-gate.md` §标题门）。
6. 标 1 条首选：截断后仍成立 + 有数字或身份 + 能兑现；情绪短句默认不当首选。

### 七型公式（结构 + Prism 出声示例）

| 公式 | 结构 | 示例（Prism 风格，非上游原句） |
|---|---|---|
| 数字清单 | 身份 + 必装/推荐 + N 个 + 对象 | 中文创作者必装的 7 个开源 AI 工具（附实测） |
| 我+代价+收获 | 我用 X 做了 Y（夸张量）+ 得到 Z | 我把 62 个大厂开源项目整理成一个 Skill 合集 |
| 反转结论 | 以为是 A，其实是 B / 不是 X，是 Y | 做小红书封面，缺的不是灵感，是这套流程 |
| 速成教程 | 时长或字数 + 精通/速通/保姆级 + 对象 | 30 分钟用开源工具做完公众号头图 |
| 社会证明 | Star/下载/大厂/热榜 + 对象 + 干成了什么 | GitHub 趋势第一的开源仓库，把整本书炼成 Skill |
| 对比站队 | A 和 B 到底选哪个 / 实测 A 和 B | Codex 和 Cursor 到底选哪个？同本资料实测 |
| 情绪短句 | 短、口语、带慌/杀疯了/卷到 | 开源社区这周杀疯了，一个晚上三个新工具 |

## 路径 B：无明确选题 → 4 个方向

8 个选题模板（槽位可迁移到电商/职场/教育，不硬套语料产品名）：

1. 必装清单  2. 亲测复盘  3. 从 0 到 1 教程  4. 热点产品落地
5. 对比抉择  6. 开源神器安利  7. 身份场景化  8. 反常识/情绪钩

流程：

1. 空输入：先用当前热点（WebSearch/热榜）找 1 个可写新工具/新事件，再套模板；搜不到热点就用品类 7/8 出可复用方向。
2. 关键词：映射到最匹配模板，出 **4 个方向，模板不重复**。
3. 每个方向给 3 条候选标题，公式不重复。
4. 全部过标题门，最后给 1 个「最值得先写」（时效 × 身份 × 可执行）。

## 硬规则

- 主标题约 18–32 字（可见字符计，含标点/数字/英文）；工具名尽量进前 16 字。
- 数字必须具体：7、50、209 页、3.5 万 Star；禁止「多个 / 一系列 / 干货合集」。
- 第一人称优先：「我用 / 我让 / 我把 / 亲测」通常优于「如何如何」。
- 身份词是点击开关：创作者、上班族、电商商家、体制内、一人公司；缺身份可补但要标「正文按该身份写场景」。
- 口语 > 书面；禁用震惊/重磅/炸裂/必看（原稿自带且要求保留除外）。
- 附赠括号是履约承诺：标题写「附教程/提示词/开源仓库」，正文必须有对应物。
- 社会证明数字必须可核查（GitHub API / README / 榜单快照）；没有公开数据就换公式。
- 一组标题禁止同义改写：6 条公式重复或只改两个字 = 不合格。
- 换赛道只搬槽位（结构），不把语料里的 Codex/WorkBuddy/Skill 硬套进无关选题。
- 不编 Star、下载量、实验样本量、对比分数。

## 缺元素怎么补

| 缺什么 | 可以补 | 不可以补 |
|---|---|---|
| 身份 | 按内容推断一个并标注需兑现 | 同时堆三个身份 |
| 数字 | 用正文真实可数条数；没有就换不依赖数字的公式 | 编造 Star/下载量/样本量 |
| 结果 | 用草稿已有结论收紧 | 发明没做过的「反超 8.7 分」 |
| 附赠 | 仅当用户确定会提供教程/提示词/仓库 | 空挂「附完整教程」 |

## 交接

- 输出 Markdown，不用 JSON。
- 每条候选都带「兑现点」；过 `anti-slop-gate.md` §标题门。
- 下一步：把首选标题交给 form-produce 进入成稿；`recommended_next_harness: qa`（标题门在 qa 侧复核）。
